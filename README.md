# 다정이

초보운전 멘탈케어

면허는 있는데 도로 위에 서는 일이 아직 무서운 사람을 위한 앱입니다. 조수석에 사람이 앉아 있고, 차가 보내 주는 신호 중에서 놓치기 쉬운 것만 골라 한 문장으로 말합니다. 같은 말을 계속 반복하지 않고, 여러 가지가 겹치면 하나씩 차례로 말합니다.

평소에는 "놓친 게 있으면 말해 드릴게요"만 보입니다. 말이 나갈 때는 화면 한가운데에 그 상황의 단어가 크게 뜨고, 문장은 그 아래에 있습니다.

이렇게 말합니다.

- 차선유지 경고등이 켜지면, 차선을 밟고 있는지 봐 달라고 합니다.
- 큰 길에서 흐름보다 한참 느리게 가면, 주변 차와 속도를 맞추자고 합니다.
- 달리면서 깜빡이를 오래 켜 두면, 이제 꺼도 된다고 알려 줍니다.
- 깜빡이를 켠 채 길이 막히거나 속도가 잘 나지 않으면, 끼어들지 못해도 괜찮다고 합니다.
- 속도가 갑자기 줄었다 늘기를 반복하면, 앞차와 간격을 넉넉히 두자고 합니다.
- 후진 기어가 들어가면, 사이드미러와 백미러도 같이 보자고 합니다.

내비게이션이 하는 길 안내는 따라 하지 않습니다. 카메라로 차선이나 옆 차를 보는 것도 아닙니다. 차가 이미 켜 둔 경고등, 기어, 깜빡이, 속도와 경로의 정체를 읽고, 그 순간에 한 번 더 살펴보라는 말을 건넵니다.

화면을 누르며 운전하게 두지 않았습니다. 말은 주차 중일 때 나갑니다. 달리는 중에도 말하게 하려면 운전 중 사용 앱으로 심사를 따로 받아야 합니다.

디버그 빌드를 열면 오른쪽 위에 **시연**이 있습니다. 위의 여섯 문장을 차례로 들려 주고, 화면에는 실제 차량 신호가 아니라고 적습니다.

## 빌드

JDK 17과 Android SDK Platform 34가 필요합니다. Pleos 음성, 차량, 내비게이션 SDK는 `https://nexus-playground.pleos.ai/repository/maven-releases/` 에서 받습니다.

```
gradlew.bat :app:assembleDebug
```
