# 초보운전

조수석에 앉은 사람이, 초보가 놓치기 쉬운 조작을 한 문장으로 말해 주는 Pleos Connect 앱입니다.

평소에는 "놓친 게 있으면 말해 드릴게요"와 사람이 보입니다. 말이 나갈 때는 키워드가 화면을 채우고, 문장은 그 아래에 나옵니다.

## 말

| 키워드 | 문장 | 나올 때 |
| --- | --- | --- |
| 차선 | 차선을 밟고 있는지 확인하세요 | 차선유지 경고등이 켜질 때 |
| 흐름 | 주변 차들과 흐름을 맞추세요 | 제한속도 60 이상인 길에서, 깜빡이 없이 너무 느리게 갈 때 |
| 깜빡이 | 깜빡이를 꺼도 돼요 | 멈추지 않은 채로 깜빡이가 오래 켜져 있을 때 |
| 끼어들기 | 끼어들지 못해도 괜찮아요 | 깜빡이를 켠 채 정체 구간이거나, 제한속도보다 많이 느릴 때 |
| 간격 | 앞차와의 간격을 넉넉히 두세요 | 짧은 시간에 속도가 크게 줄거나 늘기를 반복할 때 |
| 미러 | 사이드미러, 백미러도 같이 보세요 | 후진 기어일 때 |

경로는 다시 읽어 주지 않습니다. 차선 안의 위치와 옆 차선 차량 수는 읽을 수 없습니다. 차선은 차선유지 경고등으로, 끼어들기는 경로의 정체와 속도로 대신합니다.

운전 중 사용 앱으로 선언하지 않았습니다. 말은 주차 중일 때만 나가고, 주행 중에는 시스템이 앱을 막을 수 있습니다.

디버그 빌드에는 오른쪽 위에 **시연**이 있습니다. 여섯 문장을 차례로 보여 주며, 화면에는 실제 차량 신호가 아니라고 적습니다.

## 빌드

JDK 17, Android SDK Platform 34, Pleos Connect 에뮬레이터가 필요합니다. 음성, 차량, 내비게이션 SDK는 `https://nexus-playground.pleos.ai/repository/maven-releases/` 에서 받습니다.

```
gradlew.bat :app:assembleDebug
```
